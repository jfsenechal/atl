● Ce qui se passe

  Les deux mails reçus montrent la même chose : l'envoi fonctionne depuis le 
  cron, mais Symfony croit qu'il a échoué.

  - Le mail « Test mail CRON 11:36:03 » est bien arrivé, alors que le même
    passage a fini par Process failed with exit code -1: (ProcessStream.php:77,
    exit 255).
  - Dans le mail d'erreur de 11:24, le message en file a été retenté 3 fois,
    puis mis dans failed. Chaque essai a probablement réellement envoyé le mail,
    donc il a dû partir 4 fois.

  Dans une tâche cron OVH, PHP n'arrive pas à lire le code de retour de sendmail
  : proc_close() renvoie -1, même quand le mail est accepté. native:// traite
  ce -1 comme un échec. Avec --queue --count=3, tu as peut-être reçu les 3 mails
  de test en plusieurs exemplaires chacun.

  Deuxième problème : le crash final (exit 255) vient du mail d'erreur envoyé
  par monolog. La pile se termine par [internal function]: 
  BufferHandler->close(). Le handler de déduplication se vide tout seul à la fin
  du script, via sa propre fonction d'arrêt, donc le whatfailuregroup placé
  autour de lui (commit aec304e) ne le protégeait pas.

  Corrections (non commitées)

  1. Nouveau transport ovh://default
     (src/AcMarche/Mercredi/src/Mailer/Transport/). Il utilise le même sendmail
     que native:// et accepte « exit code -1 » seulement quand sendmail n'a rien
     affiché. Un vrai refus reste une erreur, parce que sendmail affiche alors
     la raison, comme le sendmail: fatal: User … not allowed vu en SSH.
  2. config/packages/monolog.yaml : l'ordre est maintenant deduplicated → 
     mail_safe (whatfailuregroup) → mailer. Le filet de sécurité est donc à
     l'intérieur et protège aussi le vidage en fin de script. Je n'ai pas pu
     reproduire ce crash en local, ni avant ni après la modification. Ce
     correctif repose donc sur la lecture de la pile d'appels et du code de
     Monolog.
  3. DEPLOY.md recommande maintenant MAILER_DSN=ovh://default.
  4. Tests : tests/Mailer/Transport/OvhSendmailTransportTest.php. Toute la suite
     passe (36 tests).
